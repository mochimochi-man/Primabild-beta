# Primabild β

[English](README.en.md) | [日本語](README.jp.md)

Copyright 2026 mochimochi-man

Android 10以降対応のお絵描きアプリです。レイヤーやフィルタ、特殊ペンなど、一般的な機能は一通り搭載しています。

テスト公開のため、GitHubにて公開しています。テスト公開にあたって制限している機能はありません。予定している機能をすべて使用することができます。

## 特徴

- **はみ出し基準レイヤー**：線画のレイヤーを「はみ出し基準レイヤー」に設定すると、他のレイヤーで描くペンやブラシ、塗りつぶしツールは、はみ出し基準レイヤーを超えないようになります。
- **3D変形ツール**：範囲指定した部分をZ方向に回転させることができます。
- **パレット合成**：カラーパレットパネルの任意の色を長押しし、色を二つ選択すると、二つの色の中間色を生成することができます。
- **拡張パレット**：カラーパレットパネルの拡張ボタンから、あらかじめ用意されたパレットを呼び出すことができます。
- **レイヤーからカラーを抽出**：拡張パレットにある機能で、選択中のレイヤーにある画像から、色区分を指定してパレットを生成できます。任意の画像からパレットを生成したいときに便利です。
- **ロングストロークペン**：スタビライザー機構により、長い線を安定して描くことができます。ゆっくり描画するので、やや遅く感じるかもしれません。
- **解像度基準Gペン・丸ペン**：編集中のファイルの解像度を基準に、自動的に太さが変化するGペン・丸ペンです。
- **スクリーントーンペン**：スクリーントーンと同様、線数と濃度を指定して、ペンのようにスクリーントーンを描くことができます。どこから描いてもトーンの網がずれることはありません。スクリーントーンは解像度を基準として生成するので、正しく動作させるには、解像度が正しく設定されている必要があります。
- **タイルパターンペン**：スクリーントーンペンに似た仕組みで、記号などをタイルパターンとして描くことができます。

詳細な使い方は、アプリをインストール後、設定からマニュアルを開いて確認してください。

## インストール方法

1. [Releases](https://github.com/mochimochi-man/Primabild-beta/releases)で一番新しいバージョンを開き、**Assets**からAPKをダウンロードし、Androidのファイラーから開いてインストールしてください。
2. インストールの許可を求められた場合は、案内に従って設定画面を開き、使用しているファイラーやブラウザに対して「不明なアプリのインストール」の「この提供元のアプリを許可」を有効にしてください。
