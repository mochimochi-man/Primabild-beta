# Primabild β

[English](README.en.md) | [日本語](README.jp.md)

Copyright 2026 mochimochi-man

Primabild is a drawing app for Android 10 and later. It includes a full range of standard features, such as layers, filters, and specialized pens.

The app is available on GitHub for testing. No features are restricted in this test release. All planned features are available to use.

## Features

- **Boundary Reference Layer**: Set your line art layer as a boundary reference layer to keep pens, brushes, and fill tools used on other layers from painting beyond its boundaries.
- **3D Transform Tool**: Rotate a selected area in the Z direction.
- **Palette Color Mixing**: Long-press a color in the color palette panel and select two colors to generate a color halfway between them.
- **Extended Palettes**: Open the built-in palettes using the extension button in the color palette panel.
- **Extract Colors from a Layer**: This feature in the extended palette lets you generate a palette from the image on the selected layer, with a configurable number of color groups. It is useful for creating palettes from images of your choice.
- **Long Stroke Pen**: A stabilizer helps you draw long, steady lines. Drawing is deliberately slowed, so it may feel slightly sluggish.
- **Resolution-Based G-Pen and Maru Pen**: These pens automatically adjust their width based on the resolution of the file being edited.
- **Screentone Pen**: Draw screentones like pen strokes by specifying the line frequency and density. The tone pattern stays aligned regardless of where you start drawing. Screentones are generated based on the document resolution, so the resolution must be set correctly for them to work as intended.
- **Tile Pattern Pen**: Draw symbols and other shapes as tiled patterns using a mechanism similar to the screentone pen.

For detailed instructions, install the app and open the manual from Settings.

## Installation

1. Open the newest version on the [Releases page](https://github.com/mochimochi-man/Primabild-beta/releases), download the APK under **Assets**, and open it with your Android file manager to install it.
2. If prompted to allow installation, follow the prompt to open Settings and enable **Allow from this source** under **Install unknown apps** for the file manager or browser you are using.
